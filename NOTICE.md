Windows UI uses .NET Windows Forms. Portable releases retain Microsoft runtime license and third-party notices. The microphone adapter is compiled but its recognition accuracy and device compatibility were not tested. No account, cloud API, API key or Wispr installation is required. The application's parser and equivalence checker make no network calls. Windows SAPI behavior, available English recognition engines and device permissions depend on the operating system. No audio file is saved by this application.
