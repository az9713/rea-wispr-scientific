Why you might use it

'One over x plus one' could mean 1/(x + 1) or (1/x) + 1. A neat-looking formula can still express the wrong calculation. You need to see the interpretation, not just a polished rewrite of your words.

A concrete example. Say explicitly whether 'x plus one' is the whole denominator, or whether the final '+ 1' is outside the fraction. The app shows the grouping and generates document maths, C# code and a readable explanation from that same interpretation. You can also declare simple variable units to catch incompatible combinations.

03 / Dimensions and exactness
More than notation.
Less than a general CAS.
v times t has length dimensions when v is velocity and t is time. Adding meters to seconds is rejected. Centimeter values normalize to SI scale.
The exact checker proves supported rational-polynomial identities. It returns unknown for functions, symbolic denominators and unsupported domain manipulations. Numerical sampling is never used as proof.
(x + 1)^2  ↔  x^2 + 2*x + 1
EQUIVALENT — exact polynomial normalization

x / x  ↔  1
UNKNOWN — symbolic domain cancellation is not proved
equivalentSame exact supported polynomial, with matching dimensions and typed symbols.
differentDifferent formal polynomials or root dimensions; values may still coincide at some assignments.
unknownInput invalid, outside the exact subset, or beyond declared budgets. No guessed verdict.
Numeric previews and generated C# use IEEE doubles; equivalence uses exact rationals. Dimensions are reported separately from C# magnitude values. This is not a numerical stability or physical-validity proof.


04 / Declared language
Small enough to inspect.
Supported
  • Real scalar +, −, ×, ÷, powers and unary minus.
  • Explicit parentheses; numeric decimals; English zero–twenty.
  • sin, cos, sqrt, exp and natural log with grouped arguments.
  • Declared scalar variables and integer mass/length/time dimensions.
  • Meters, centimeters, seconds, kilograms and newtons.
  • Bounded rational-polynomial equivalence and SI code generation.
Outside this release
  • Arbitrary natural language, equations and assignments.
  • Vectors, tensors, calculus, affine temperatures and all SI dimensions.
  • General symbolic domain solving or transcendental identities.
  • Automatic cross-app insertion and Wispr integration.
  • Any measured ASR accuracy, acoustic robustness or microphone compatibility.
Read the complete grammar, precedence and budgets →
Precedence is explicit, including negative powers
Powers associate to the right: two power three power two means2^(3^2). Minus two squared means−(2^2); group a negative base to square it. Postfix squared binds to its immediate atom: two meters squared means2×meter². Group the full quantity to square its magnitude too.
Type checks do not solve symbolic domains
Known constant checks use finite-double evaluation. Symbolic division still requires a nonzero denominator. Symbolic sqrt/log/powers retain real-domain obligations. Dimension checks cannot establish numerical stability or physical meaning. Preview every expression before using it.


05 / Optional speech input
A microphone adapter,
with a clear boundary.
Pressing Start microphone creates the Windows SAPI recognizer for one English-US utterance. Stop cancels it. Received text is editable and still requires a separate Parse action.
No microphone was accessed during implementation or verification. The adapter is compiled, not acoustically tested. A compatible installed Windows recognizer and device permissions may be unavailable.
The app saves no audio file and calls no speech cloud API. Windows speech components and uncalibrated recognition confidence remain outside parser guarantees. Transcript input always works independently of ASR.

06 / Existing features matter
Wispr already rewrites text.
This project defines a language.
Wispr's official desktop documentation describes beta Transforms, custom instructions, diff/undo and optional post-dictation transforms. Its dictionary supports technical vocabulary. A generic math-rewrite prompt overlaps that baseline.
This independent implementation adds a specific contract: deterministic tokens, explicit AST, declared dimensions, conservative rejection and bounded exact equivalence. It makes no claim to reproduce Wispr's engine or patch its desktop app.
